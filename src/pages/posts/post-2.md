# Mi materia favorita y el stack web

Si tuviera que elegir la materia que más me ha gustado hasta ahora en la carrera, sin duda sería **Programación Web**.

## Tecnologías que he estado aprendiendo:

* **React:** Para la creación de interfaces de usuario modernas y componentes reutilizables.
* **API REST & GraphQL:** Para la comunicación entre el cliente y el servidor de forma eficiente.
* **Astro:** Justo la tecnología que estoy explorando ahora mismo para construir este sitio web rápido y dinámico.

Aprender el ecosistema web me ha permitido conectar lógica con interfaces funcionales.
